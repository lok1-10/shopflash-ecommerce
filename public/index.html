Features

Everything built in Java

Two core roles with a complete transactional workflow.

User Auth

Email/password login with last-login timestamp tracking per session.

  • PreparedStatement queries
  • Last login timestamp
  • Role-based menus

Seller Portal

Sellers register shops and list products with categories, prices & stock.

  • Shop by email registration
  • Add products with stock
  • View own listings

Shopping Cart

Add products by ID with quantity and get a full cost breakdown.

  • Add by product ID + qty
  • JOIN-based display
  • Subtotal per item

Order Placement

Real-time stock check. Stock auto-decremented. Cart cleared on success.

  • Stock validation
  • Auto stock decrement
  • Cart auto-clear

MySQL + JDBC

Full DB connectivity using mysql-connector-j with PreparedStatements throughout.

  • mysql-connector-j 26.10
  • PreparedStatement safety
  • Auto-increment PKs

Console UI

Box-drawing menus, emoji prompts, and printf-formatted product tables.

  • ASCII box-drawing menus
  • printf table output
  • Emoji indicators

Database

MySQL Schema

Four normalized tables. Click Copy to grab the SQL.

users
CREATE TABLE users (
  user_id    INT AUTO_INCREMENT PRIMARY KEY,
  name       VARCHAR(100),
  email      VARCHAR(100) UNIQUE,
  password   VARCHAR(100),
  last_login TIMESTAMP
);
sellers
CREATE TABLE sellers (
  seller_id INT AUTO_INCREMENT PRIMARY KEY,
  user_id   INT,
  shop_name VARCHAR(100),
  FOREIGN KEY (user_id)
    REFERENCES users(user_id)
);
products
CREATE TABLE products (
  product_id       INT AUTO_INCREMENT PRIMARY KEY,
  seller_id        INT,
  product_name     VARCHAR(100),
  product_category VARCHAR(50),
  price            DECIMAL(10,2),
  stock_quantity   INT
);
cart
CREATE TABLE cart (
  cart_id    INT AUTO_INCREMENT PRIMARY KEY,
  user_id    INT,
  product_id INT,
  quantity   INT,
  FOREIGN KEY (user_id)
    REFERENCES users(user_id)
);
Quick Start

Run in 3 steps

1

Create the database

Create ecommerce1 in MySQL and run all four schema statements above.

mysql -u root -p -e "CREATE DATABASE ecommerce1;"
2

Compile with JDBC driver

Add mysql-connector-j.jar to classpath when compiling.

javac -cp mysql-connector-j.jar EcommerceSystem.java
3

Run the system

Execute with the jar on classpath. The interactive menu launches immediately.

java -cp .;mysql-connector-j.jar DBMS.EcommerceSystem
