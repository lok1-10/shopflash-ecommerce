Features

Everything you need in one system

Built around two core roles — Buyers and Sellers — with a full transactional flow.

User Authentication

Secure login and registration for both buyers and sellers. Tracks last login timestamp on every session.

  • Email + password login
  • PreparedStatement protection
  • Session-based last login tracking

Seller Portal

Sellers can register their shop, list products with category/price/stock and manage their inventory.

  • Shop registration via user email
  • Add products with stock tracking
  • View personal product listings

Shopping Cart

Users browse products, add them to cart with specified quantities, and see a detailed cost breakdown.

  • Add by product ID + quantity
  • Live subtotal calculation
  • Persistent cart per user

Order Placement

Place orders with real-time stock validation. Stock is decremented automatically upon successful order.

  • Stock sufficiency check
  • Atomic order total calculation
  • Auto cart clear after order

MySQL Integration

Full JDBC connectivity to MySQL via mysql-connector-j. All queries use PreparedStatements for safety.

  • mysql-connector-j driver
  • PreparedStatement everywhere
  • Auto-increment primary keys

Clean Console UI

Elegant ASCII box menus with emoji icons. Formatted table output using printf for products and cart.

  • Box-drawing character menus
  • Formatted product tables
  • Error messages with emoji

static void addProduct(int sellerId) {
    try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {

        System.out.println("❌ " + e.getMessage());
    }
}

static void viewCart(int userId) {
    try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {
        String sql = "SELECT p.product_name, p.price, c.quantity "
                   + "FROM cart c JOIN products p ON c.product_id = p.product_id "
                   + "WHERE c.user_id=?";

        PreparedStatement ps = conn.prepareStatement(sql);
        ps.setInt(1, userId);
        ResultSet rs = ps.executeQuery();

        double total = 0;
        System.out.println("🛒 YOUR CART");
        System.out.printf("%-15s %-10s %-10s %-10s\n",
            "Product", "Price", "Qty", "Total");

        while (rs.next()) {
            double price = rs.getDouble("price");
            int    qty   = rs.getInt("quantity");
            double sub   = price * qty;
            total += sub;
            System.out.printf("%-15s ₹%-9.2f %-10d ₹%-10.2f\n",
                rs.getString("product_name"), price, qty, sub);
        }
        System.out.println("Total Amount: ₹" + total);
    } catch (Exception e) {
        System.out.println("❌ " + e.getMessage());
    }
}

static void placeOrder(int userId) {
    try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {
        PreparedStatement ps = conn.prepareStatement(
            "SELECT product_id, quantity FROM cart WHERE user_id=?");
        ps.setInt(1, userId);
        ResultSet rs = ps.executeQuery();
        double total = 0;

        while (rs.next()) {
            int pid = rs.getInt("product_id");
            int qty = rs.getInt("quantity");

            PreparedStatement ps2 = conn.prepareStatement(
                "SELECT price, stock_quantity FROM products WHERE product_id=?");
            ps2.setInt(1, pid);
            ResultSet rs2 = ps2.executeQuery();

            if (rs2.next()) {
                if (rs2.getInt("stock_quantity") < qty) {
                    System.out.println("❌ Not enough stock!");
                    return;
                }
                total += rs2.getDouble("price") * qty;
                PreparedStatement ps3 = conn.prepareStatement(
                    "UPDATE products SET stock_quantity = stock_quantity - ? WHERE product_id=?");
                ps3.setInt(1, qty); ps3.setInt(2, pid);
                ps3.executeUpdate();
            }
        }
        System.out.println("🎉 Order placed! Total ₹" + total);
        conn.createStatement().executeUpdate(
            "DELETE FROM cart WHERE user_id=" + userId);
    } catch (Exception e) {
        System.out.println("❌ " + e.getMessage());
    }
}
Database

MySQL Schema

Four normalized tables powering the entire system. Run these to get started.

users 
CREATE TABLE users (
  user_id    INT AUTO_INCREMENT
             PRIMARY KEY,
  name       VARCHAR(100),
  email      VARCHAR(100) UNIQUE,
  password   VARCHAR(100),
  last_login TIMESTAMP
);
sellers 
CREATE TABLE sellers (
  seller_id INT AUTO_INCREMENT
            PRIMARY KEY,
  user_id   INT,
  shop_name VARCHAR(100),
  FOREIGN KEY (user_id)
    REFERENCES users(user_id)
);
products 
CREATE TABLE products (
  product_id       INT AUTO_INCREMENT
                   PRIMARY KEY,
  seller_id        INT,
  product_name     VARCHAR(100),
  product_category VARCHAR(50),
  price            DECIMAL(10,2),
  stock_quantity   INT
);
cart 
CREATE TABLE cart (
  cart_id    INT AUTO_INCREMENT
             PRIMARY KEY,
  user_id    INT,
  product_id INT,
  quantity   INT,
  FOREIGN KEY (user_id)
    REFERENCES users(user_id)
);
Getting Started

Run it locally in 3 steps

01

Setup MySQL Database

Create the ecommerce1 database and run the four CREATE TABLE statements above.

mysql -u root -p -e "CREATE DATABASE ecommerce1;"
02

Add the JDBC Driver

Place mysql-connector-j-*.jar on your classpath. Download from MySQL Downloads.

javac -cp mysql-connector-j.jar EcommerceSystem.java
03

Run the System

Execute with the driver on classpath. The interactive console menu will launch immediately.

java -cp .;mysql-connector-j.jar DBMS.EcommerceSystem
